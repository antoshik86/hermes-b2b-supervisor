# 🤖 Демонстрационный микро-стенд: Hermes Agent (Битрикс24 + 1C:ERP + Telegram)

Рабочий демонстрационный стенд для презентации заказчику (позаказное B2B-производство, завод металлоконструкций/оборудования). 
Показывает, как **Hermes Agent** выступает «умным надзирателем и помощником» над **Битрикс24** (CRM, звонки, задачи) и **1C:ERP** (склад, металл, дебиторка, график цехов).

---

## 📦 Установка

```powershell
git clone https://github.com/antoshik86/hermes-b2b-supervisor.git
cd hermes-b2b-supervisor
pip install -r requirements.txt
```

---

## 🚀 3 Способа запуска стенда

### Способ 1: Интерактивная консоль (Рекомендуется для быстрого показа)
Красивый терминальный интерфейс на базе `rich` с таблицами, прогресс-барами и подсветкой статусов.
```powershell
python demo_runner.py
```
*Нажмите `7` для запуска сквозного прогона всех 4 блоков за 15 секунд.*

---

### Способ 2: Визуальный веб-дашборд (Для скриншотов, видео и шеринга экрана)
Современный веб-интерфейс в темной теме (Glassmorphism), готовый для записи демо-видео и демонстрации в Google Meet / Zoom:
```powershell
python web_dashboard.py
```
После запуска откройте в браузере: **http://127.0.0.1:8000**  
*(Или просто дважды кликните по файлу `static/index.html` — он полностью автономен и работает даже без запуска сервера).*

---

### Способ 3: Живой Telegram-бот
Если в `.env` указан `TELEGRAM_BOT_TOKEN`:
```powershell
python bot_runner.py
```
В боте работают кнопки:
- 📞 **Разбор звонков**: забирает звонок из CRM, дает оценку и ставит авто-задачу.
- 🧠 **1C:ERP Суфлёр**: выдает тактическую справку по клиенту и остаткам.
- 🚨 **1С:ERP Аудит**: сканирует зависшие заказы на производстве.
- 📊 **Дашборд РОПа**: выводит вечернюю сводку.
- 🎙 **Голосовые сообщения**: наговорите «Поставь задачу технологу Петрову проверить чертеж к 15:00» — бот распознает и создаст задачу в CRM.

## 🎯 4 Сценария для созвона с заказчиком

| Сценарий | Что делает Hermes | Что видит заказчик |
|---|---|---|
| **1. Контроль звонков Битрикс24** | Анализирует диалог менеджера Иванова по чек-листу (приветствие, ТЗ, сроки, следующий шаг, вежливость). Фиксирует оценку 4.5/10. | Карточка с аудитом в таймлайне сделки CRM + авто-постановка срочной задачи `tasks.task.add` на перезвон клиенту. |
| **2. Суфлёр по 1C:ERP** | Подтягивает дебиторку (185 000 ₽, 6 дн. просрочки), остатки на складе ГП (200 шт.) и сырье в цеху (уголок ст3 в наличии). | Готовый совет менеджеру: «Отгрузить готовые 200 шт. только при условии закрытия старого долга + 50% предоплаты за новую партию». |
| **3. Аудит производства 1С** | Проверяет регистры: Заказ №ПЗ-1084 (простой 38 ч.), Партия №ВЫП-412 (выпуск без списания металла), ПП №892 (нет статьи ДДС). | Сводка директору со списком виновных сотрудников + персональные алерты исполнителям в Telegram. |
| **4. Постановка задач голосом** | Голосовая команда босса: «Поставь задачу технологу Петрову проверить чертеж к 15:00». Выделяет суть, дедлайн, ответственного. | Созданная задача в Битрикс24 с высоким приоритетом и дедлайном. |

## ⚙️ Структура проекта

```
hermes-b2b-supervisor/
├── config.py                 # Конфигурация и подгрузка ключей из окружения
├── sample_data.py            # Реалистичные B2B кейсы (металлоконструкции, клиенты, 1С)
├── demo_runner.py            # Интерактивное Rich-меню в терминале
├── web_dashboard.py          # FastAPI сервер дашборда
├── bot_runner.py             # Скрипт живого Telegram-бота
├── static/
│   └── index.html            # Автономный визуальный дашборд
└── modules/
    ├── bitrix_client.py      # Клиент REST API Битрикс24 (tasks.task.add, crm.timeline)
    ├── call_analyzer.py      # Чек-лист анализа звонков и авто-задачи
    ├── erp_prompter.py       # Суфлёр по остаткам, металлу и дебиторке
    ├── erp_auditor.py        # Аудитор производства и ошибок учета 1С
    ├── task_parser.py        # Парсер естественной речи и поручений
    └── telegram_reporter.py  # Вечерний дашборд РОПа
```
