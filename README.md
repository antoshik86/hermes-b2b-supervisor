# 🤖 Hermes Agent: Контур B2B-контроля (Битрикс24 + 1C:ERP + Telegram)

Архитектурное решение и рабочий прототип интеграции **Hermes Agent** с **Битрикс24** (CRM, телефония, задачи) и **1C:ERP** (склад, металл, дебиторка, график цехов) для позаказного B2B-производства.

Поддерживает работу как в автономном режиме (веб-дашборд / CLI), так и в качестве **нативного плагина/набора навыков для Hermes Desktop (`Hermes.exe`) и Hermes Gateway**.

---

## 🏛️ Архитектура и интеграция с Hermes

Полное техническое описание, схема взаимодействия данных и потоки запросов приведены в документе:
👉 **[HERMES_ARCHITECTURE.md](./HERMES_ARCHITECTURE.md)**

### Готовые навыки Hermes (Native Skills)
Навыки оформлены в стандарте Hermes Agent (`SKILL.md`) и готовы к прямому подключению в `~/.hermes/skills/` или `plugins/`:
- **[b2b-sales-auditor](./skills/b2b-sales-auditor/SKILL.md)** — аудит звонков менеджеров, расчёт баллов по чек-листу, запись в таймлайн CRM и авто-постановка корректирующих задач при нарушениях.
- **[erp-copilot](./skills/erp-copilot/SKILL.md)** — суфлёр менеджера по долгам, свободным остаткам готовой продукции и сырью в цеху 1С:ERP.
- **[erp-production-auditor](./skills/erp-production-auditor/SKILL.md)** — регулярный аудит зависших заказов на производство и выпусков без списания материалов.
- **[voice-task-dispatcher](./skills/voice-task-dispatcher/SKILL.md)** — приём голосовых сообщений из Telegram и постановка задач в Битрикс24.

Манифест плагина для авто-регистрации: `hermes_manifest.json`.

## 🚀 3 Способа запуска стенда для демонстрации

### Способ 1: Визуальный веб-дашборд (Для созвона и демонстрации экрана)
Современный интерфейс в тёмной теме (Glassmorphism), разработанный для наглядного показа работы агента:
```powershell
python web_dashboard.py
```
Открыть в браузере: **http://127.0.0.1:8000**  
*(Файл `static/index.html` автономен и может открываться локально напрямую без сервера).*

---

### Способ 2: Интерактивная консоль (Быстрый прогон всех сценариев)
```powershell
python demo_runner.py
```
*Нажмите `7` для последовательного тестирования всех 4 блоков за 15 секунд.*

---

### Способ 3: Живой Telegram-бот с голосовым управлением
```powershell
python bot_runner.py
```
Принимает текст и голосовые сообщения, на лету обращаясь к CRM и 1С.

## 🎯 4 Сценария контроля

| Сценарий | Что делает Hermes | Результат в CRM / 1C |
|---|---|---|
| **1. Контроль звонков Битрикс24** | Забирает запись разговора, проверяет по 5 критериям чек-листа (приветствие, ТЗ, сроки, следующий шаг, вежливость). | Комментарий с оценкой в таймлайне сделки + авто-задача менеджеру на срочный перезвон, если нет следующего шага. |
| **2. Суфлёр по 1C:ERP** | Подтягивает дебиторку (185 000 ₽), остатки на складе ГП (200 шт.) и сырье в цеху (уголок ст3 в наличии). | Готовая коммерческая подсказка менеджеру: «Отгрузить 200 шт. только при закрытии старого долга + 50% предоплаты». |
| **3. Аудит производства 1С** | Проверяет регистры: Заказ №ПЗ-1084 (простой 38 ч.), Партия №ВЫП-412 (выпуск без списания металла), ПП №892 (нет статьи ДДС). | Сводка нарушений руководству + персональные алерты исполнителям. |
| **4. Постановка задач голосом** | Руководитель наговаривает: «Поставь задачу технологу Петрову проверить чертеж к 15:00». | Созданная задача в Битрикс24 с дедлайном и высоким приоритетом. |

## ⚙️ Структура репозитория

```
hermes-b2b-supervisor/
├── HERMES_ARCHITECTURE.md    # Концепция и техническая спецификация интеграции
├── hermes_manifest.json      # Манифест навыков для загрузки в Hermes Agent
├── skills/                   # Нативные навыки Hermes (SKILL.md)
│   ├── b2b-sales-auditor/
│   ├── erp-copilot/
│   ├── erp-production-auditor/
│   └── voice-task-dispatcher/
├── config.py                 # Переменные окружения и ключи
├── sample_data.py            # B2B кейсы (металлоконструкции, клиенты, 1С)
├── demo_runner.py            # Интерактивное меню в терминале
├── web_dashboard.py          # FastAPI сервер дашборда
├── bot_runner.py             # Скрипт живого Telegram-бота
├── static/
│   └── index.html            # Визуальный дашборд
└── modules/
    ├── bitrix_client.py      # Клиент REST API Битрикс24
    ├── call_analyzer.py      # Чек-лист анализа звонков
    ├── erp_prompter.py       # Суфлёр по остаткам и дебиторке
    ├── erp_auditor.py        # Аудитор производства 1С
    ├── task_parser.py        # Парсер естественной речи
    └── telegram_reporter.py  # Вечерний дашборд РОПа
```
