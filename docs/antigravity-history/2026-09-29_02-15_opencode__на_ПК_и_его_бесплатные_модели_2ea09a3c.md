### 1. Как установить OpenCode на ПК (Windows)

Для Windows есть несколько способов установки:

* **Через NPM (Node.js):**
  ```powershell
  npm install -g opencode-ai
  ```
* **Через пакетные менеджеры Windows:**
  ```powershell
  scoop install opencode
  # или
  choco install opencode
  ```
* **Через WSL (Windows Subsystem for Linux — рекомендовано разработчиками):**
  ```bash
  curl -fsSL https://opencode.ai/install | bash
  ```

После установки агент запускается в папке проекта командой:
```bash
opencode
```
