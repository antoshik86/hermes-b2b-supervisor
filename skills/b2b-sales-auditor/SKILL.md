# B2B Sales Auditor Skill for Hermes Agent

## Когда активируется:
- По вебхуку Битрикс24 о завершении звонка (`ONVOXIMPLANTCALLFINISHED`).
- По запросу пользователя в Telegram или веб-дашборде («Проанализируй звонок ID...»).

## Чек-лист оценки качества звонка:
1. **Приветствие и корпоративный стандарт** (0-2 балла).
2. **Выявление технических параметров и ТЗ** (чертежи, маркировка стали, объёмы, сроки) (0-2 балла).
3. **Презентация возможностей завода / сроков** (0-2 балла).
4. **Фиксация чёткого следующего шага** (дедлайн КП, дата повторного звонка) (0-2 балла).
5. **Вежливость и клиентоориентированность** (0-2 балла).

## Действия агента:
1. Вычислить общий балл от 1.0 до 10.0.
2. Сформировать структурированный комментарий для таймлайна сделки (`crm.timeline.comment.add`).
3. Если следующий шаг НЕ зафиксирован ИЛИ оценка < 6.0:
   - Вызвать метод `tasks.task.add` для постановки срочной задачи менеджеру.
   - Тема: `[СРОЧНО: АУДИТ ЗВОНКА] Исправить ошибку ведения клиента`.
   - Дедлайн: текущее время + 30 минут.
4. Отправить запись в журнал ежедневного аудита для вечернего дашборда РОПа.
