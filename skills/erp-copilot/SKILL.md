# 1C:ERP Co-Pilot Skill for Hermes Agent

## Когда активируется:
- При открытии сделки в Битрикс24.
- При запросе менеджера в Telegram («Проверь клиента ООО Вектор», «Что по остаткам для заказа #123»).

## Интеграция с 1С:ERP:
Запрашивает HTTP-сервис 1C:ERP:
- `GET /hs/b2b/partner/{partner_id}/summary`

## Логика анализа Гермеса:
1. **Проверка дебиторки:**
   - Если есть просроченный долг > 0 ₽: блокировать отгрузку в долг, требовать закрытия старой задолженности.
2. **Проверка склада готовой продукции:**
   - Определить, сколько единиц готово к немедленной отгрузке сегодня.
3. **Проверка сырьевого обеспечения производства:**
   - Если требуется изготовление остатка: проверить наличие металла/сырья на складе снабжения и загрузку производственных линий.
4. **Синтез коммерческого предложения:**
   - Сформулировать краткую фразу, которую менеджер может сразу озвучить или отправить клиенту (например: «Готовы отгрузить 200 шт. со склада сегодня при закрытии старого долга, оставшиеся 300 шт. изготовим за 4 дня»).
