# Voice Task Dispatcher Skill for Hermes Agent

## Когда активируется:
- При получении голосового аудиофайла (`voice` / `audio`) или текста с поручением в Telegram-боте.

## Логика работы агента:
1. **Транскрибация:** конвертация голосовой дорожки в текст через локальный или облачный Whisper.
2. **Семантический анализ поручения:**
   - Выявление исполнителя (сопоставление ФИО с базой пользователей Битрикс24).
   - Выделение формулировки сути задачи.
   - Парсинг относительных и абсолютных дедлайнов («к 15:00», «до конца недели», «срочно»).
   - Определение уровня приоритета (срочно / обычная).
3. **Создание задачи в CRM:**
   - Вызов REST API Битрикс24 `tasks.task.add` с указанием `RESPONSIBLE_ID`, `DEADLINE`, `PRIORITY`.
4. **Обратная связь:**
   - Отправка подтверждения руководителю в Telegram со ссылкой на созданную задачу в Битрикс24.
